# AI提示词技巧

==增加超强==：[AI提示词](AI提示词.md)

---

## 一、核心原则：清晰表达，把AI当作对话伙伴

好的提示词并不需要复杂咒语。核心只有一个——**结构化地告诉AI你要什么**。  
把AI看作一个能力强但毫无背景知识的新同事，你需要完整地说明任务，而非让它“猜”。

### 通用公式

**我要（做）____，要给____用，希望达到____效果，但需要当心____问题**

> **示例**  
> 我要做一份从北京到日本的旅游攻略，给我爸妈用，希望让他们开心玩20天，但我担心他们腿脚不便，容易累。

该公式覆盖了任务目标、受众、期望结果与约束条件，适用于绝大多数日常与专业场景。

## 二、高级技巧

### 1. 批判性思维激发（“反向PUA”）

主动要求模型自我批判，倒逼其深入分析，避免浮于表面的回答。

- “请先列出10个反对理由，再给出最终方案。”
- “如果你是挑剔的老板，会怎么批评这个方案？”
- “复盘你刚才的回答，指出不足并给出改进版。”

### 2. 风格模仿与语气控制

直接指定风格或语气，无需暗号，效果更稳。

- **风格模仿**：“模仿鲁迅文风，写一段关于AI的评论。”  
  “参考以下文案风格，为我的产品写一段介绍：”
- **语气控制**：“用毒舌语气评论这一现象。”  
  “用轻松幽默的口吻解释这个技术概念。”  
  “以正式严谨的学术风格撰写这段内容。”

### 3. 激发深度思考

在提示词中显性要求展示思考过程，让推理更透明可靠。

- “请一步步思考，展示完整推理过程。”
- “在给出答案前，先分析可能存在的逻辑问题。”
- “回答中同时加入你的批判性思考。”

## 三、专业场景提效：去除“AI味儿”

AI生成文本常带有平滑过渡、虚词堆砌、文末爱总结等“机器感”。以下分场景指令可有效改善。

| 场景              | 指令要点                                                |
| --------------- | --------------------------------------------------- |
| **降AI感**        | 过渡词换成最基础的常用词；使用简单直接的表达，避免生僻词；删去文末多余总结；确保逻辑自然衔接。     |
| **保持主题与逻辑一致**   | 重组段落，确保思路清晰递进；统一语气风格；调整段落间衔接，避免跳跃，使首尾逻辑自然贯通。        |
| **句子润色**        | 重写为介于书面学术与口语之间的风格；确保每句有明确主语；拆分复杂长难句，优先用短句；避免不日常的词汇。 |
| **简化结构，增强清晰度**  | 简化复杂句子结构但保留关键信息；改写冗长或重复的句子，确保每句话只传达一个核心意思。          |
| **转换语气以适应场合**   | 正式：简洁、清晰、专业；说服性：用词有力、逻辑严密；非正式：友好、对话式。               |
| **增加具体细节**      | 确保句子与段落间逻辑连接清晰，使用一致过渡词，明确因果或时间顺序；必要时重组结构以提升可读性与流畅度。 |
| **突出核心观点，删减冗余** | 突出核心观点与支撑证据，删除重复或偏题内容；对冗长描述进行概括，核心信息不失真。            |
| **调整节奏与句式多样性**  | 交替使用长短句打破单调；关键处用短句加强力度；适当穿插问句、感叹句增强变化，同时匹配整体语气。     |

## 四、教育与学术赋能

- **文献速读**：用300字总结论文核心结论，标注3个创新点与2个潜在缺陷。聚焦研究目的、方法、结果，突出贡献与不足。
- **参考文献整理**：查找近3年关于[主题]的5篇高被引论文，按APA格式列出，注明作者、年份、期刊、卷号、页码。
- **学术翻译**：将中文摘要译为英文，确保专业术语准确，符合IEEE标准。保持原文逻辑，突出研究重点，避免语义模糊。
- **期刊润色与重写**：以Nature格式重写方法论，突出实验可重复性。详细描述步骤、样本选择、数据分析方法。
- **学术辩论**：列举支持与反对[理论]的各3个证据，用表格对比权重，从实验数据、理论基础、应用场景等维度分析。
- **数据分析报告**：对[数据集]进行描述性统计、相关性分析与回归建模，用图表展示关键发现，并解释其科学意义。
- **研究假设设计**：针对[研究主题]提出3个可验证假设，结合文献说明依据，并设计初步实验方案。
- **综述撰写**：围绕[主题]梳理近5年进展，归纳3个主要研究方向，分析热点与趋势，引用至少10篇权威文献。

## 五、当前主流大模型的最佳实践

以下方法适用于GPT-4o、Claude、Gemini、DeepSeek等主流模型。

1. **思维链**：要求逐步推理，提升复杂任务可靠性。  
   → “请一步步思考并解答这个问题。”

2. **少样本提示**：提供示例，准确传递任务模式。  
   → 示例1：“这个产品太棒了！” → 正面 / 示例2：“服务很差。” → 负面  
   现在请分类：“价格合理，质量不错。”

3. **角色提示**：在特定场景提升专业度，但已非必需。  
   → “你是一位经验丰富的Python开发者，请帮我优化这段代码。”

4. **结构化输出**：明确格式要求，便于后续处理。  
   → “请用JSON格式输出，包含‘标题’、‘摘要’、‘关键词’字段。”

5. **分步指令**：将复杂任务拆解为可执行的子步骤。  
   → “1.总结核心观点；2.列出3个支持论据；3.提出1个反驳观点。”

6. **迭代优化**：多轮对话逐步打磨。  
   → “这是初稿，请针对逻辑连贯性提出修改建议。” → “根据建议修改后，再检查语法错误。”

## 六、重要提醒

1. **通用性**：本文技巧普遍适用于主流大模型，非特定模型专属。  
2. **模型在进化**：许多早期必需的“提示词技巧”已被模型内化，无需再显式强调。  
3. **实践出真知**：最好的提示词来自真实使用与反复迭代，不必拘泥于模板。

**从清晰的表达开始，持续试验，让AI成为你值得信赖的思维伙伴。**
