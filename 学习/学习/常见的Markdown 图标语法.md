# 常见的Markdown 图标语法

## ✅ 推荐的 Emoji 图标网站（Markdown 友好）

### 1. [Emojipedia](https://emojipedia.org/)

- 📚 **全球最全的 Emoji 资料库**
- 🔍 支持按关键字搜索（如：science, test tube, microscope）
- 🧬 示例：输入 "science" 可找到 🧪、🔬、🔭 等图标

---

### 2. [Get Emoji](https://getemoji.com/)

- ✨ 极简页面，可快速浏览和复制所有 Emoji
- ✅ 不含广告，无需登录，适合快速取用

---

### 3. [Unicode Table](https://unicode-table.com/)

- 🔢 提供 Emoji 及其 Unicode 编码
- 🧪 附带 HTML/Unicode/JS 表达形式，适合开发者和写技术文档
- 🌍 支持多语言界面，适合国际化写作场景

---

### 4. [Iconify](https://icon-sets.iconify.design/)

- 🧩 包含 **超过 100+ icon 库**，如 Material Design、Font Awesome、Simple Icons 等
- ⚡ 支持 Markdown 插件或 Vue/React 使用
- 🎨 可下载 SVG 图标，适合用在静态 Markdown 页面（如 Hugo、Docsify）

---

### 5. [Font Awesome (Emoji 类图标)](https://fontawesome.com/icons)

- 🔧 适合开发者使用 Markdown + HTML 图标混排
- 🚀 支持实用图标（如 flask、dna、microscope）
- 💡 可搭配 Web 或静态站点（如 GitBook、MkDocs）使用
