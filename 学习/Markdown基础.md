## 基本语法

### 标题语法

#### 使用#号标记

1. 使用`#`号来表示1-6标题  
   一级标题对应一个`#`号，二级标题对应两个`#`号，以此类推。
2. `#`号和标题之间要有一个空格
3. `#`号前面不能有其他字符
4. 一级标题是唯一的

### 段落语法

Markdown段落没有特殊的格式，直接写文字就好

#### 段落的换行

1. 使用两个及以上空格加回车
2. 在段落后使用一个空行  
3. HTML换行标签：再要换行的部分加`<br>`

注：在vscode中写Markdown，在安装preview enhance插件后，插件默认勾选了break on single new line,导致直接回车就换段落,请务必**关闭**

### 强调语法

#### 粗体

使用`**`包围文字  
eg.**这是加粗的字**

#### 斜体

使用`*`包围文字
eg.*这是斜体文字*

#### 粗斜体组合

使用`***`包围文字
eg.***这是粗斜体文字***

### 分隔线语法

在一行中使用三个以上的`*`（`_`或者`-`）来建立一个分隔线，行内不能有其他东西

1. 空格可以与三个以上`*`（或者`_`）随意组合，空格大于等于0即可
2. `-`至少有三个，并且任意两个`-`之间要有一个空格，空格总数大于等于1即可
3. 为了兼容性，分隔线的前后要添加空白行

### 删除线语法

在文字的两端加上两个`~`添加删除线  
eg.~~这是添加了删除线的文本~~

### 引用语法

要创建块引用，请在段落前添加一个`>`符号

> 这是引用

#### 多段落的块引用

块引用可以包含多个段落。为段落间的空白行添加一个`>`符号

> 这是第一段
>
> 这是第二段

#### 嵌套块引用

块引用可以嵌套，一个`>`符号是最外层，两个`>`符号是第一层嵌套，以此类推  
>最外层
>>第一层嵌套
>>>第二层嵌套

#### 引用块内的其他元素

引用块内可以包含几乎所有其他Markdown元素

### 列表语法

#### 有序列表

要创建有序列表，请在每个列表项前添加数字并紧跟一个英语句点和一个空格

1. 第一项  
   1. 第一小项  
      2. 第一小小项 

#### 无序列表

要创建无序列表，请在每个列表项前添加减号（-）和一个空格。

- 第一项
  - 第一小项
    - 第一小小项

#### 列表嵌套

- 子列表要缩进2个空格
  - 要保持一致的缩进长度
    - 可以无限嵌套，但实际中不建议超过3层

> >

#### 任务列表（复选框列表）

任务列表是Github风格Markdown的拓展功能，可以嵌套（并非标准Markdown语法，部分平台不支持）

格式：  
`- [ ] `未完成的任务  
`- [x] `已完成的任务  
`1. [ ] `未完成的任务


示例：  

>- [ ] 未完成的任务
>- [x] 已完成的任务

>1. [ ] 未完成的任务
>    1. [x] 已完成的任务  

注：列表标记和方括号间要有空格，方括号内要有空格或x，方括号与文本间要有空格

#### 引用类型链接

引用样式链接是一种特殊的链接，它使URL在Markdown中更易于显示和阅读。参考样式链接分为两部分：与文本保持内联的部分以及存储在文件中其他位置的部分，以使文本易于阅读

##### 链接的第一部分格式

引用类型的链接的第一部分使用两组括号进行格式设置。第一组方括号包围应显示为链接的文本。第二组括号显示了一个标签，该标签用于指向您存储在文档其他位置的链接

> 第二组括号中的标签不区分大小写，可以包含字母，数字，空格或标点符号

`- [b站][1]`

##### 链接的第二部分格式

引用类型链接的第二部分使用以下属性设置格式：

1. 链接与前文要空行，此时链接才会隐藏
2. 放在括号中的标签，其后紧跟一个冒号和至少一个空格
3. 链接的URL，可以选择将其括在尖括号中
4. 链接的可选标题，可以将其括在双引号，单引号或括号中
5. 可以将链接的第二部分放在Markdown文档中的任何位置。有些人将它们放在出现的段落之后，有些人则将它们放在文档的末尾（通常放在末尾）

`[1]: https://www.bilibili.com/`

>具体实现：  
>- [B站][1]  

[1]: https://www.bilibili.com/

##### 简化写法

>

当参考标签与链接文字相同时，可以省略第二个方括号：  
我喜欢用` [github][] `来管理代码  

`[github]: <https://github.com>  `

>具体实现：
>我喜欢用 [github][] 来管理代码

[github]: https://github.com

参考链接的优势：

- 文档正文更清爽，不被长URL打断
- 便于链接的统一管理和更新
- 相同链接可以重复使用，避免重复定义

#### 图片alt文本的重要性

alt文本（替代文字）在图片无法显示是提供替代信息，同时对无障碍访问和SEO很重要  
>好的alt文本示例：   
>`![苹果公司总部大楼外观，现代玻璃幕墙建筑](./images/apple-headquarters.jpg)`  
>`![网站流量统计图表，显示过去六个月的访问量呈上升趋势](./charts/traffic-stats.png)`  
>`![用户登录界面，包含用户名和密码输入框](./screenshots/login-page.png)`

---

避免的alt文本：
> `![图片](image.jpg)`  
> // 太简单，没有描述性  
> `![ ](image.jpg)`  
> // 完全没有 alt 文本  
> `![点击这里](image.jpg)`  
> // 不描述图片内容  

alt文本最佳实践：
- 简洁但有描述性
- 描述图片的主要内容和用途
- 避免使用“图片”、“照片”的冗余词
- 对于装饰性图片，可以用空格
- 考虑上下文，提供有用信息

### 表格

要添加表，请使用三个及以上减号（`-`）创建每列的标题，并使用竖线（`|`）分隔每列

- 表头和数据之间必须有分隔线
- 两端的竖线是可选的，但建议保留以提高可读性

  | B站    |   抖音 |
  | :----- | -----: |
  | 动漫   |   短剧 |
  | 长视频 | 短视频 |

Tip：使用连字符和竖线创建表格可能很麻烦。为了加快该过程，请尝试使用 [Markdown Tables Generator](https://www.tablesgenerator.com/markdown_tables)

#### 对齐方式

可以设置的表格对齐方式：

- `---:` 设置内容和标题栏居右对齐
- `:---` 设置内容和标题栏居左对齐
- `:---:` 设置内容和标题栏居中对齐

其中的减号要三个及以上

### 文本高亮

文本高亮不是标准Markdown语法，但许多拓展支持  
常见语法（部分平台不支持）：  
`这是==高亮==文本`  
HTML替代方案：  
`这是<mark>高亮文本</mark>`  
>示例：  
>这是==高亮==文本  
>这是<mark>高亮文本</mark>

### 下划线

下划线不是标准Markdown语法  
格式：`<u>这个句子将被划线</u>`
> 示例：
> <u>这个句子将被划线</u>

### 支持的HTML元素

不在 Markdown 涵盖范围之内的标签，都可以直接在文档里面用 HTML 撰写。目前支持的 HTML 元素有：`<kbd> <b> <i> <em> <sup> <sub> <br>`等。  
如；  
>`使用 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Del</kbd> 重启电脑 `   
>使用 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Del</kbd> 重启电脑
