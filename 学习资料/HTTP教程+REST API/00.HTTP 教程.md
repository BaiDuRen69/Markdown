## HTTP 协议教程

本教程是 HTTP 协议的 **完整 9 篇入门系列** ，面向前后端初学者。从报文结构、请求方法一路讲到状态码、头部、会话管理与 HTTPS 加密，最后用 curl 实战收尾，每篇都配有可复制的真实报文与命令示例。

HTTP（HyperText Transfer Protocol，超文本传输协议）是 Web 通信的基础协议。每次你打开网页、提交表单、调用 API，背后都是 HTTP 在工作。它由 Tim Berners-Lee 在 1989 年发明，是万维网的基石——理解 HTTP 是所有 Web 开发者的必修课。

## 先看一个 HTTP 交互

下面是一次最典型的 HTTP 请求 + 响应（中间空行分隔，上半是请求，下半是响应）：

```
GET /api/users HTTP/1.1
Host: example.com
User-Agent: Mozilla/5.0
Accept: application/json

HTTP/1.1 200 OK
Content-Type: application/json
Content-Length: 27

{"id":1,"name":"Alice"}
```

## 推荐学习路径

如果你是完全的零基础，建议按下面 3 个阶段推进：

- **阶段 1 看懂报文** ：简介 → 报文结构 → 请求方法 → 状态码。学会打开浏览器 F12 看懂 Network 面板里的每一行。
- **阶段 2 掌握细节** ：头部 → 请求体与 Content-Type。学会正确发请求、解析响应、上传文件。
- **阶段 3 工程进阶** ：Cookie 与 Session → HTTPS → curl 实战。学会登录态保持、安全传输、命令行调试。

每篇都建议你 **边读边敲** ：把示例报文/命令复制到浏览器开发者工具或终端里，亲手跑一遍。HTTP 是协议层的东西，光看不练很容易忘。
